# Web Audio Lab

A laboratory for web audio API.

## Run

1.  Host the files using `npx http-server`, `python -m http.server` or Live Server (VSCode extension).
2.  Open Chrome using [open-chrome-no-auto-play.sh](open-chrome-no-auto-play.sh).
3.  Open localhost and [main.html](main.html).
    NOTE: Microphone is available in only `https:`, `file:///` or `localhost`.
